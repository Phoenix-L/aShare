# Shock Reversion Intraday Research Notebook

This folder is a lightweight research notebook for documenting strategy experiments.

## Purpose

Use this notebook to keep short, structured experiment notes so research decisions are easy to review later.

## How to use the template

1. Copy `notebook/TEMPLATE.md`.
2. Rename the copy to a timestamped filename (for example: `20260324_153000_gap_filter_test.md`).
3. Fill in each section:
   - Context
   - Change
   - Hypothesis
   - Experiment
   - Observation
   - Diagnosis
   - Decision
   - Next Step

## Where to store entries

- Put note entries in `research/shock_reversion_intraday/notebook/`.
- Put polished high-level takeaways in `research/shock_reversion_intraday/summaries/`.
