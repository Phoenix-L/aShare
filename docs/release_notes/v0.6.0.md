# v0.6.0 — Metric Normalization & Selection Stabilization

This release finalizes the pre-ladder cleanup for `shock_reversion_intraday` and establishes a stable normalized metric baseline for the next development phase.

## Highlights

- **Metric normalization**
  - Unified the reporting pipeline around decimal-based return and drawdown metrics.
  - Removed inconsistent percentage-style compatibility fields from release artifacts.

- **Selection system**
  - Stabilized the scoring-based selection flow written to `selection_report_v2.csv`.
  - Eliminated the empty-selection failure mode for viable experiment sets by ranking surviving configurations deterministically.

- **Reporting improvements**
  - Improved run-level consistency across diagnostics, trade exports, and performance reports.
  - Standardized `capital_efficiency` as the bridge between trade-level returns and realized portfolio returns.

- **Strategy stabilization**
  - Cleaned and simplified `shock_reversion_intraday` for the pre-ladder milestone.
  - Confirmed the strategy no longer depends on legacy trend / ATR / ART filters.

## Known Limitations

- No ladder or pyramiding entry logic yet.
- Position sizing is still fixed by `trade_unit`.
- Margin support is available, but portfolio-level financing limits and optimization are not yet enforced.

## Next Phase Preview

- Ladder-based multi-leg entry management.
- Capital-efficiency optimization and better utilization of available equity.
